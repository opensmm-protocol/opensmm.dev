Demo catalog. This is a demo catalog snapshot from a gateway node's mock fixtures — sample service names and rates, not sellable supply. Ordering becomes possible after a provider (an SMM panel or another supply node) connects to the gateway. Settlement is tested with USDC on Base Sepolia (testnet); mainnet USDC is not enabled yet.

Demo catalog of 4,100 sample growth services exposed through the OpenSMM protocol. Every entry is a mock fixture of the gateway node itself ("synthetic": true): an AI agent can search it via MCP tools or plain HTTP /v0, but an order is possible only after a provider is connected. Rates, limits and quality flags are illustrative, not quotes from the market.
