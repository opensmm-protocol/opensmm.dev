Заказ SMM-услуги из Claude Desktop

Claude Desktop подключается к узлу OpenSMM по stdio: конфиг claude_desktop_config.json запускает MCP-сервер как локальный процесс (npm run mcp). Порт, ключи и учётные данные не нужны. Всё идёт на mock-каталоге: каждая услуга помечена synthetic: true, заказы остаются в статусе REQUIRES_PAYMENT и не оплачиваются.

1. Установить узел (около 2 минут)

Нужны Node.js ≥ 22.18 и сборка Claude Desktop с поддержкой MCP: конфигурация mcpServers, протокол MCP 2025-06-18.

bash
git clone https://github.com/opensmm-protocol/mcp-server.git
cd mcp-server
npm ci

Отдельный npm run gateway не нужен: конфиг Claude Desktop сам запускает MCP-сервер по stdio — тот же сервер, который регистрирует mcp.json в корне репозитория.

2. Скопировать конфиг и перезапустить Claude Desktop

Скопируйте claude_desktop_config.json из examples/claude-desktop/ в конфиг Claude Desktop.

json
{
  "mcpServers": {
    "opensmm": {
      "command": "npm",
      "args": ["run", "mcp"],
      "cwd": "/path/to/mcp-server"
    }
  }
}

Куда класть: macOS — ~/Library/Application Support/Claude/claude_desktop_config.json, Windows — %APPDATA%\Claude\claude_desktop_config.json. Замените "cwd": "/path/to/mcp-server" на абсолютный путь вашего checkout'а и полностью перезапустите Claude Desktop. Скрипт mcp в package.json есть по умолчанию.

3. Что попросить у агента

Откройте новый чат и попросите Claude пройти сценарий одним запросом:

text
Через инструменты opensmm вызови search_services и подтверди, что каждая
услуга помечена synthetic. Затем вызови get_quote для первой услуги с
количеством 100 и ссылкой https://t.me/opensmm_example, вызови create_order
с этой котировкой и clientReference claude-demo-1, затем вызови create_order
ещё раз с той же котировкой и тем же референсом. Покажи оба orderId.

Ожидаемый результат:

  • search_services → каталог, у каждой услуги synthetic: true — mock-каталог, не реальное предложение;
  • get_quote → osmm_quote_..., сумма в USDC, количество 100;
  • первый create_order → osmm_order_..., paymentStatus: REQUIRES_PAYMENT;
  • второй create_order → тот же orderId, второй заказ не создан.

Повтор — главная проверка протокола: один clientReference даёт один заказ на любом транспорте, включая stdio.

Если что-то выглядит неправильно

  • Услуга не помечена synthetic — остановитесь и не заказывайте: демо не должно заказывать реальное предложение. Оплата не проходит, значит ни один провайдер ничего не исполняет.
  • Инструменты opensmm не появились — проверьте cwd (нужен абсолютный путь вашего checkout'а) и полностью перезапустите Claude Desktop.

Честные ограничения

  1. Страница пересказывает examples/claude-desktop/README.md; точные шаги и конфиг — там.
  2. Сценарий для всех стеков сразу: docs/AGENT_QUICKSTART.md.
  3. Каталог — mock (synthetic: true): реальных услуг, цен и заказов здесь нет; оплата заказа в этом гайде не проходит.
  4. Другие стеки: быстрый старт агента, заказ из Cursor, агент в стиле LangChain.
