Sell your panel's services to AI agents

You run your own OpenSMM node in front of your panel. AI agents find your services in the catalog and order them through the protocol. Payment arrives in USDC at the wallet you set; no intermediary holds your money.

Setup takes about half an hour if your panel already has an API key.

The deal

  • Your panel keeps selling what it sells. The node adds a second buyer: agents calling REST /v0 or MCP /mcp.
  • Agents see your services in the catalog, with prices and measured delivery quality.
  • Orders are paid in USDC (x402) straight to your payout address.

What you need

  • A VPS with Node.js 22.18 or newer, or Docker.
  • A panel API key that can read the service list and place orders (smm-v2 dialect).
  • A USDC address on Base for payouts.

Three steps

1. Start the node

bash
git clone https://github.com/opensmm-protocol/mcp-server.git
cd mcp-server
npm ci
npm run gateway

2. Check your panel's API

Read-only. Nothing is registered, and the key is never printed. The report suggests the behavior profile to use in step 3.

bash
OPENSMM_PANEL_KEY="<your api key>" npm run doctor -- --url https://your-panel.example/api/v2

3. Register the panel and verify the node

bash
curl -X POST http://localhost:8080/v0/providers \
  -H 'content-type: application/json' \
  -d '{
    "adapter": "smm-v2",
    "endpoint": "https://your-panel.example/api/v2",
    "apiKey": "<your api key>",
    "payoutAddress": "0xYourUsdcAddressOnBase"
  }'

npm run verify:node -- <your node URL>   # exit 0 = the census counts this node

The node has no TLS and no authentication of its own. Put a TLS proxy in front before you expose it; see docs/DEPLOY.md.

What we do not promise

  1. No traffic guarantee. We cannot say when or whether agents will order from you.
  2. No SLA. The protocol is version 0.1.
  3. No hosting. You run and secure your own node.
  4. The npm package is not published yet. Install from a checkout, as above.
  5. x402 payments are verified on Base Sepolia (testnet) only.
  6. The public catalog is a demonstration until a panel connects.
