Заказ SMM-услуги из Claude Code

Готового примера именно под Claude Code в репозитории mcp-server пока нет — здесь нет выдуманного конфига или кода. Узел OpenSMM открывает те же MCP-инструменты, что и примеры для Claude Desktop и Cursor; страница честно ведёт на ближайший рабочий пример из examples/ и docs/AGENT_QUICKSTART.md. Всё идёт на mock-каталоге: каждая услуга помечена synthetic: true, заказы остаются REQUIRES_PAYMENT и не оплачиваются — ключ, аккаунт и деньги не нужны.

1. Поднять узел (около 2 минут)

Нужен Node.js ≥ 22.18. Запустите узел с mock-каталогом — он слушает REST /v0 и MCP /mcp.

bash
git clone https://github.com/opensmm-protocol/mcp-server.git
cd mcp-server
npm ci
npm run gateway

Узел печатает в stderr строку вида gateway listening on http://localhost:8080 (REST /v0, MCP /mcp; provider: mock, mock catalog — not real supply). Проверка из другого терминала: curl -s http://127.0.0.1:8080/v0/services | head -30 — у каждой услуги "synthetic": true. Порт занят? PORT=8081 npm run gateway. Другие сбои — сбои запуска узла.

2. Как подключить MCP-сервер

В examples/README.md есть готовые блоки конфигурации MCP-сервера — для stdio и для HTTP. Они описаны как работающие с любым MCP-клиентом; точный синтаксис команды Claude Code — в документации Claude Code, в этом репозитории его нет.

json — stdio (npm run mcp)
{
  "mcpServers": {
    "opensmm": {
      "command": "npm",
      "args": ["run", "mcp"],
      "cwd": "/path/to/mcp-server"
    }
  }
}
json — HTTP (POST /mcp запущенного узла)
{
  "mcpServers": {
    "opensmm": {
      "url": "http://127.0.0.1:8080/mcp"
    }
  }
}

Конфигурация соответствует mcp.json в корне репозитория: сервер io.github.opensmm-protocol/mcp-server, пакет @opensmm/mcp-server, протокол MCP 2025-06-18. Замените /path/to/mcp-server на абсолютный путь вашего checkout'а.

3. Ближайший рабочий пример: каталог → котировка → заказ → повтор

Чтобы увидеть весь сценарий без Claude Code, запустите готовый tool-calling скрипт из быстрого старта — он вызывает те же три инструмента, которые получит и MCP-клиент в Claude Code.

bash
node examples/langchain/agent.mjs http://127.0.0.1:8080 --client-reference my-first-order
text — ожидаемый вывод
transport: MCP tools over POST /mcp (LangChain-style tool calls)
tools:     search_services, get_quote, create_order
catalog:   MOCK — every service is marked synthetic: not real supply, no real money
service:   osmm_svc_tg_members_std — Telegram Channel Members — Standard
quote:     osmm_quote_... — 0.241200 USDC for 100 (mock rate)
order:     osmm_order_... — REQUIRES_PAYMENT, clientReference "my-first-order"
replay:    osmm_order_... — same orderId, no second order created
done:      LangChain-style agent OK

Строки order: и replay: — один и тот же orderId: один clientReference даёт один заказ на любом транспорте. Полный разбор — в docs/AGENT_QUICKSTART.md.

4. Что на самом деле вызвал агент

  1. search_services — читает каталог; у каждой записи synthetic: true. Примеры отказываются продолжать, если услуга не помечена как mock.
  2. get_quote — цена одной услуги для количества 100 и ссылки https://t.me/opensmm_example. Котировка расходуется один раз, под каждый заказ нужна своя.
  3. create_order — неоплаченный заказ (по REST — HTTP 402 с телом заказа). Ничего не оплачивается и не исполняется.
  4. create_order ещё раз с тем же clientReference — повтор возвращает сохранённый заказ, а не создаёт второй.

REST-эквиваленты: GET /v0/services, POST /v0/quotes, POST /v0/orders, опрос — GET /v0/orders/:id.

Если что-то выглядит неправильно

  • is not marked synthetic — узел не на mock-каталоге; остановитесь и не заказывайте. Перезапустите узел без настроенного провайдера.
  • ECONNREFUSED — узел из шага 1 не запущен или слушает другой порт.
  • IDEMPOTENCY_CONFLICT — этот clientReference уже принадлежит заказу из другой котировки: передайте исходную через --quote или возьмите новый референс.
  • HTTP 402 на POST /v0/orders — ожидаемый ответ, а не сбой.

Честные ограничения

  1. Отдельного готового примера под Claude Code в репозитории нет: точный синтаксис подключения — в документации Claude Code, а не на этой странице.
  2. Страница пересказывает examples/README.md и docs/AGENT_QUICKSTART.md; рабочие конфиги и шаги — там.
  3. Каталог — mock (synthetic: true): реальных услуг, цен и заказов здесь нет, курс в примере — тестовый, оплата не проходит.
  4. Другие стеки: быстрый старт агента, заказ из Claude Desktop, заказ из OpenAI Agents SDK.
