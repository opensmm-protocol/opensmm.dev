Заказ SMM-услуги из n8n

Готовый workflow для n8n 1.x: узлы HTTP Request проходят REST /v0 локального узла — каталог, котировка, заказ, повтор и опрос. Всё на mock-каталоге (synthetic: true), заказы остаются REQUIRES_PAYMENT.

1. Поднять узел

Нужен Node.js ≥ 22.18. Ключ, аккаунт и деньги не нужны: узел отдаёт mock-каталог.

bash
git clone https://github.com/opensmm-protocol/mcp-server.git
cd mcp-server
npm ci
npm run gateway

Порт занят или узел не стартует — сбои запуска узла.

2. Импортировать workflow

В n8n: Workflows → Import from File → examples/n8n/workflow.json, откройте workflow и нажмите Execute Workflow. Файл привязан к n8n 1.x и узлу HTTP Request typeVersion: 4.2.

Чтобы направить его на другой узел, поменяйте только baseUrl в узле Config.

3. Что делают узлы workflow

  • Config — baseUrl, quantity: 100, link, новый clientReference (n8n-demo-…)
  • GET catalog — GET /v0/services → mock-каталог
  • Guard: mock only — не пускает дальше, если первая услуга не synthetic: true
  • Create quote — POST /v0/quotes → osmm_quote_...
  • Create order — POST /v0/orders → osmm_order_..., REQUIRES_PAYMENT
  • Replay order — POST /v0/orders → тот же orderId
  • Verify idempotency — падает, если два orderId разные
  • Poll order — GET /v0/orders/:id → сохранённый заказ

4. Чего ждать

  • Create order и Replay order отвечают HTTP 402, пока заказ не оплачен; опция «Never Error» пропускает тело заказа дальше. Это ожидаемо, а не сбой.
  • Повтор возвращает тот же заказ: один clientReference — один orderId. Ничего не оплачивается и не исполняется.
  • Узел Guard останавливает workflow, если в каталоге есть услуга без пометки mock, — демо не может создать заказ у реального поставщика.

Честные ограничения

  1. Страница пересказывает docs/AGENT_QUICKSTART.md; точные версии и конфиги — там.
  2. Каталог — mock (synthetic: true): реальных услуг, цен и заказов здесь нет, курс в примерах — тестовый.
  3. Это демо-workflow на mock-узле; оплата и реальный поставщик в нём не участвуют (x402 — на тестовой сети, см. оплата по x402).
