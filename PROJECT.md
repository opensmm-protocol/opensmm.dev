# OpenSMM website (opensmm.dev)

Static site for the OpenSMM protocol, served by GitHub Pages from `main` (`/`).
Branches start from `develop`; pull requests target `develop`.

## Language rule: English only

Everything in this repository is written in English: pages, `<title>`/meta/Open Graph/JSON-LD,
alt text, `llms.txt`, `mcp.json`, `.well-known/**`, scripts, comments, docs, commit messages,
branch names, and pull request titles and descriptions. No Cyrillic characters anywhere in
tracked text files.

The `Lint English only` workflow (`.github/workflows/lint-english.yml`) fails a pull request
when `git grep -nIP '[\x{0400}-\x{04FF}]'` finds a match. Run the same command locally before pushing.

## Layout

- Root `*/index.html` — pages (URLs must not change).
- `en/**` — mirror of the root pages; canonical points at the root page.
- `catalog/**` — generated by `node build-catalog.mjs`; do not edit by hand.
- `sitemap.xml`, `robots.txt`, `llms.txt` — crawler files.
