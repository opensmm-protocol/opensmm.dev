Заказ SMM-услуги из OpenAI Agents SDK

Готового примера именно под OpenAI Agents SDK в репозитории mcp-server пока нет — здесь нет выдуманного кода или обёрток инструментов. Узел OpenSMM открывает инструменты search_services, get_quote и create_order по MCP на POST /mcp; страница честно ведёт на ближайший рабочий пример — SDK-независимый MCP-клиент из examples/ и docs/AGENT_QUICKSTART.md. Всё идёт на mock-каталоге: каждая услуга помечена synthetic: true, заказы остаются REQUIRES_PAYMENT и не оплачиваются — ключ, аккаунт и деньги не нужны.

1. Поднять узел (около 2 минут)

Нужен Node.js ≥ 22.18. Запустите узел с mock-каталогом — он слушает REST /v0 и MCP /mcp.

bash
git clone https://github.com/opensmm-protocol/mcp-server.git
cd mcp-server
npm ci
npm run gateway

Узел печатает в stderr строку вида gateway listening on http://localhost:8080 (REST /v0, MCP /mcp; provider: mock, mock catalog — not real supply). Проверка из другого терминала: curl -s http://127.0.0.1:8080/v0/services | head -30 — у каждой услуги "synthetic": true. Порт занят? PORT=8081 npm run gateway. Другие сбои — сбои запуска узла.

2. Как подключить MCP-сервер

В examples/README.md есть готовый блок конфигурации MCP-сервера по HTTP. Он описан как работающий с любым MCP-клиентом; точный способ обернуть MCP-инструменты в OpenAI Agents SDK — в документации этого SDK, в этом репозитории его нет.

json — HTTP (POST /mcp запущенного узла)
{
  "mcpServers": {
    "opensmm": {
      "url": "http://127.0.0.1:8080/mcp"
    }
  }
}

Конфигурация соответствует mcp.json в корне репозитория: сервер io.github.opensmm-protocol/mcp-server, пакет @opensmm/mcp-server, протокол MCP 2025-06-18. Для stdio-подключения блок npm run mcp — в examples/README.md.

3. Ближайший рабочий пример: MCP-клиент без SDK

Чтобы увидеть весь сценарий без OpenAI Agents SDK, запустите готовый examples/mcp-client.mjs — он говорит по JSON-RPC напрямую с POST /mcp: initialize → search_services → get_quote → create_order дважды. Никаких зависимостей, MCP SDK, ключей и денег.

bash
node examples/mcp-client.mjs http://127.0.0.1:8080 --client-reference my-first-order
text — ожидаемый вывод
node:      http://127.0.0.1:8080
transport: MCP over Streamable HTTP (JSON-RPC on POST /mcp)
catalog:   MOCK — every service is marked synthetic: not real supply, no real money
service:   osmm_svc_tg_members_std — Telegram Channel Members — Standard
quote:     osmm_quote_... — 0.241200 USDC for 100 (mock rate)
order:     osmm_order_... — REQUIRES_PAYMENT, clientReference "my-first-order"
replay:    osmm_order_... — same orderId, no second order created
done:      MCP client OK

Строки order: и replay: — один и тот же orderId: один clientReference даёт один заказ на любом транспорте. Полный разбор — в docs/AGENT_QUICKSTART.md.

4. Что на самом деле вызвал агент

  1. initialize — клиент согласовывает протокол MCP 2025-06-18.
  2. search_services — читает каталог; у каждой записи synthetic: true. Примеры отказываются продолжать, если услуга не помечена как mock.
  3. get_quote — цена одной услуги для количества 100 и ссылки https://t.me/opensmm_example. Котировка расходуется один раз, под каждый заказ нужна своя.
  4. create_order — неоплаченный заказ. По REST это HTTP 402 с телом заказа; ничего не оплачивается и не исполняется.
  5. create_order ещё раз с тем же clientReference — повтор возвращает сохранённый заказ, а не создаёт второй.

REST-эквиваленты: GET /v0/services, POST /v0/quotes, POST /v0/orders, опрос — GET /v0/orders/:id.

Если что-то выглядит неправильно

  • is not marked synthetic — узел не на mock-каталоге; остановитесь и не заказывайте. Перезапустите узел без настроенного провайдера.
  • ECONNREFUSED — узел из шага 1 не запущен или слушает другой порт.
  • IDEMPOTENCY_CONFLICT — этот clientReference уже принадлежит заказу из другой котировки: передайте исходную через --quote или возьмите новый референс.
  • HTTP 402 на POST /v0/orders — ожидаемый ответ, а не сбой.

Честные ограничения

  1. Отдельного готового примера под OpenAI Agents SDK в репозитории нет: способ обернуть MCP-инструменты в SDK — в документации SDK, а не на этой странице.
  2. Страница пересказывает examples/README.md и docs/AGENT_QUICKSTART.md; рабочий MCP-клиент и шаги — там.
  3. Каталог — mock (synthetic: true): реальных услуг, цен и заказов здесь нет, курс в примере — тестовый, оплата не проходит.
  4. Другие стеки: быстрый старт агента, агент в стиле LangChain, заказ из Claude Code.
