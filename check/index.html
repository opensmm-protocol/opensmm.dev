Проверка узла OpenSMM онлайн

Введите https-адрес вашего узла — страница из браузера выполнит 4 проверки и покажет pass/fail по каждой. Ничего не регистрируется и не сохраняется.

    CORS: как включить

    Если проверка показывает «заблокировано CORS», узел жив, но браузер не получил разрешения. Добавьте на узле заголовок Access-Control-Allow-Origin: https://opensmm.dev (и ответ на preflight OPTIONS для /mcp) либо проверьте узел из терминала:

    bash
    npm run verify:node -- https://node.example.org

    Если проверка не прошла, сверьтесь со страницей сбои запуска узла · реестр узлов.

    Что эта проверка не делает

    1. Проверка идёт из вашего браузера: узел должен быть доступен по https из интернета и отдавать CORS-заголовки.
    2. Бейдж — самоотчёт оператора: реестр OpenSMM его не проверяет и не подтверждает.
    3. Заказы не создаются — только чтение и MCP initialize.
