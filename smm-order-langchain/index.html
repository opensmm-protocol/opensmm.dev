Заказ SMM-услуги из агента на LangChain

Готовый tool-calling агент против локального узла OpenSMM: search_services, get_quote, create_order — те же инструменты, что LangChain-агент получает через @langchain/mcp-adapters. Пример вызывает их напрямую по POST /mcp: LLM-ключ не нужен, пакет @langchain/* ставить не нужно, деньги не нужны. Хватает Node.js ≥ 22.18.

1. Поднять узел (около 2 минут)

bash
git clone https://github.com/opensmm-protocol/mcp-server.git
cd mcp-server
npm ci
npm run gateway

Узел печатает на stderr строку вида gateway listening on http://localhost:8080 (REST /v0, MCP /mcp; provider: mock, mock catalog — not real supply). Порт занят? PORT=8081 npm run gateway. Другие сбои запуска — сбои запуска узла.

2. Запустить агента (второй терминал)

bash
node examples/langchain/agent.mjs http://127.0.0.1:8080 --client-reference my-first-order
text
node:      http://127.0.0.1:8080
transport: MCP tools over POST /mcp (LangChain-style tool calls)
tools:     search_services, get_quote, create_order
tool:      search_services({})
catalog:   MOCK — every service is marked synthetic: not real supply, no real money
service:   osmm_svc_tg_members_std — Telegram Channel Members — Standard
tool:      get_quote({"serviceId":"osmm_svc_tg_members_std","quantity":100,"link":"https://t.me/opensmm_example"})
quote:     osmm_quote_... — 0.241200 USDC for 100 (mock rate)
tool:      create_order({"quoteId":"osmm_quote_...","link":"https://t.me/opensmm_example","clientReference":"my-first-order"})
order:     osmm_order_... — REQUIRES_PAYMENT, clientReference "my-first-order"
tool:      create_order({"quoteId":"osmm_quote_...","link":"https://t.me/opensmm_example","clientReference":"my-first-order"})
replay:    osmm_order_... — same orderId, no second order created
done:      LangChain-style agent OK

Опции: [base-url] (по умолчанию http://127.0.0.1:8080), --client-reference <ref>, --quote <quote-id> — переиспользовать котировку из прошлого запуска, --help.

3. Инвариант протокола

  • Сценарий целиком: каталог → котировка → заказ → повтор. Строки order: и replay: — один и тот же orderId: один clientReference даёт один заказ на любом транспорте.
  • Заказ остаётся в статусе REQUIRES_PAYMENT — пример не платит и ничего не исполняется.
  • Котировка расходуется один раз: под каждый заказ нужна своя; --quote переиспользует уже выпущенную.

4. Подключить настоящий LangChain-агент

Сохраните три имени инструментов и формы аргументов, которые печатает TOOLS в agent.mjs, подключите их через MCP-адаптер LangChain на адрес http://127.0.0.1:8080/mcp — и пусть модель отправляет те же вызовы.

  • search_services — поиск услуги; на mock-узле каждая услуга synthetic;
  • get_quote — нужны serviceId, quantity, link;
  • create_order — нужны quoteId, link, clientReference.

REST-эквиваленты тех же операций: GET /v0/services, POST /v0/quotes, POST /v0/orders — см. examples/rest-client.mjs.

5. Защита от живого провайдера

  • Скрипт берёт первую услугу из ответа узла — не придумывает ID — и сразу останавливается, если она не помечена synthetic: true.
  • Сообщение об ошибке: refusing to place a demo order: ... is not marked synthetic. This example orders only on the mock catalog — see examples/README.md.
  • Это защита от узла, к которому подключён живой провайдер: демо-заказ не уйдёт в реальное предложение.

Честные ограничения

  1. Страница пересказывает examples/langchain/README.md; точный вывод и опции скрипта — там.
  2. Сценарий для всех стеков сразу: docs/AGENT_QUICKSTART.md.
  3. Каталог — mock (synthetic: true): реальных услуг, цен и заказов здесь нет; курс в примере — тестовый, оплата не проходит.
  4. Другие стеки: быстрый старт агента, заказ из Claude Desktop, заказ из Cursor.
