Check your OpenSMM node online

Enter the https address of your node — the page runs 4 checks from your browser and shows pass/fail for each. Nothing is registered or stored.

    CORS: how to enable it

    If the check says "blocked by CORS", the node is alive but the browser got no permission. Add the header Access-Control-Allow-Origin: https://opensmm.dev on the node (and answer the OPTIONS preflight for /mcp), or check the node from a terminal:

    bash
    npm run verify:node -- https://node.example.org

    If a check fails, see node startup failures · node registry.

    What this check does not do

    1. The check runs from your browser: the node must be reachable over https from the internet and send CORS headers.
    2. The badge is operator self-reported: the OpenSMM registry does not verify or confirm it.
    3. No orders are created — only reads and MCP initialize.
