OpenSMM plugin for ElizaOS agents

The plugin gives an ElizaOS agent three actions: search_services, get_quote, create_order. They call an OpenSMM node over POST /mcp (initialize, tools/call). The code is an example in the repository: copy the folder, start a node and run the smoke script. No keys, no money, Node.js ≥ 22.18.

Open the example on GitHub

The node's catalog is a mock: every service is marked synthetic, there are no real services or prices. The order stays REQUIRES_PAYMENT.

Three steps to run it

1. Start the node

bash
git clone https://github.com/opensmm-protocol/mcp-server.git
cd mcp-server
npm ci
PORT=8080 npm run gateway

The node prints gateway listening on http://localhost:8080 (...; provider: mock, mock catalog — not real supply) on stderr. Startup fixes: node startup failures.

2. Check the chain in a second terminal

bash
node examples/eliza/smoke.mjs http://127.0.0.1:8080

The script runs search → quote → order → replay with the same clientReference. The replay returns the same orderId, no second order is created, exit code 0.

3. Plug the plugin into your agent

Copy examples/eliza/plugin.mjs into your agent project, register the plugin in the character and point it at http://127.0.0.1:8080/mcp. The ElizaOS version the example targets is pinned in the folder's README: the framework's API changes between versions, so the plugin is kept thin.

What each action does

  • search_services — finds a service in the node's catalog; on a mock node every service is synthetic.
  • get_quote — requires serviceId, quantity, link.
  • create_order — requires quoteId, link, clientReference. One clientReference yields one order on any transport.

REST equivalents of the same operations: GET /v0/services, POST /v0/quotes, POST /v0/orders.

Honest limits

  1. The catalog is a mock (synthetic: true): no real services, prices or fulfilment, nothing is paid.
  2. The order stays REQUIRES_PAYMENT: the plugin never pays and nothing is executed.
  3. This is an example to copy, not a published npm package and not part of the ElizaOS repository. OpenSMM core has no @elizaos/* dependency.
  4. Exact options and the ElizaOS version are in the example README.
  5. Other stacks: agent quickstart, LangChain, OpenAI Agents SDK.
