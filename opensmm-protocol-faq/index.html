FAQ протокола OpenSMM

Короткие ответы по спеке v0 и документации репозитория: что такое протокол, как заказывать, как платить и что считается узлом. Каталог пока mock.

Вопросы и ответы

  • Что такое OpenSMM?
    Открытый протокол заказа SMM-услуг для AI-агентов: каталог, котировка, заказ, оплата, статусы. Лицензия MIT, версия 0.1.0, URL-префикс /v0.
  • MCP — это и есть протокол?
    Нет. MCP — один из транспортов, REST /v0 — канонический HTTP-биндинг. Одна операция по обоим даёт одни и те же объекты; тот же clientReference — тот же orderId. Подробнее: MCP или REST.
  • Какие команды есть у протокола?
    Десять: getCapabilities, searchServices, getService, getQuote, createOrder, getOrder, cancelOrder, requestRefill, listProviders, registerProvider. cancelOrder, requestRefill и registerProvider необязательны, остальные семь обязательны. Таблица: SMM API для MCP.
  • Зачем нужна котировка?
    Заказ без котировки создать нельзя: она фиксирует услугу, количество, ссылку и сумму, истекает и расходуется ровно один раз.
  • Что значит HTTP 402 при создании заказа?
    Ожидаемый ответ: заказ создан и ждёт оплаты (REQUIRES_PAYMENT), в теле — требования оплаты. Это не ошибка.
  • Как протокол защищает от дублей заказа?
    Идемпотентность на уровне протокола: заголовок Idempotency-Key (REST) или поле clientReference (MCP). Повтор возвращает тот же заказ, тот же ключ с другими параметрами — IDEMPOTENCY_CONFLICT.
  • Как устроена оплата?
    Расчёт напрямую: деньги идут от агента к поставщику и не проходят через узел (x402, USDC). Сейчас проверено только на тестовой сети Base Sepolia; основная сеть не включена. Подробнее: оплата по x402.
  • Реальный каталог уже есть?
    Нет. Каталог на сайте и у локального узла — mock-фикстуры (synthetic: true), а не продаваемое предложение. Заказы возможны после подключения поставщика (панели или другого узла).
  • Что считается узлом?
    Публичный URL, у которого GET /v0/services отвечает 200 с JSON-массивом services, а POST /mcp с initialize — 200 с JSON-RPC result. Проверка: npm run verify:node. Подробнее: реестр узлов.
  • Как подключить свою панель?
    Через baseUrl, apiKey и профиль, без кода; доктор (npm run doctor) проверяет панель до подключения. См. подключить панель.
  • Что вне рамок версии 0.1?
    Кампании, подписки, массовые заказы, торг, автозаказы, фермы аккаунтов и A2A. Версия 0.1 — без SLA, до /v1 возможны несовместимые изменения без уведомления.

Проверить на своей машине

Локальный узел, mock-каталог, без ключей и денег (Node.js ≥ 22.18).

bash
git clone https://github.com/opensmm-protocol/mcp-server.git
cd mcp-server
npm ci
npm run gateway
curl -s http://127.0.0.1:8080/v0/services | head -30

Пошагово с заказом — быстрый старт агента; стек n8n — заказ из n8n; отличие от прямого API — OpenSMM или прямой API.
