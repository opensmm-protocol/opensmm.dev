OpenSMM protocol FAQ

Short answers from the v0 spec and repository docs: what the protocol is, how to order, how to pay and what counts as a node. The catalog is still a mock.

Questions and answers

  • What is OpenSMM?
    An open protocol for ordering social-growth services by AI agents: catalog, quote, order, payment, status. MIT licence, version 0.1.0, URL prefix /v0.
  • Is MCP the protocol?
    No. MCP is one transport; REST /v0 is the canonical HTTP binding. One operation over either yields the same objects; the same clientReference gives the same orderId. More: MCP or REST.
  • Which commands does it define?
    Ten: getCapabilities, searchServices, getService, getQuote, createOrder, getOrder, cancelOrder, requestRefill, listProviders, registerProvider. cancelOrder, requestRefill and registerProvider are optional; the rest are required. Table: SMM API for MCP.
  • Why is a quote required?
    An order cannot be created without one: a quote binds service, quantity, link and amount, expires, and is consumed exactly once.
  • What does HTTP 402 on order creation mean?
    Expected: the order exists and waits for payment (REQUIRES_PAYMENT), with payment requirements in the body. It is not an error.
  • How does the protocol prevent duplicate orders?
    Idempotency is protocol-level: the Idempotency-Key header (REST) or the clientReference field (MCP). A replay returns the same order; the same key with other parameters gives IDEMPOTENCY_CONFLICT.
  • How does payment work?
    Direct settlement: money flows from agent to supplier and never transits the node (x402, USDC). It is tested only on the Base Sepolia testnet; mainnet is not enabled. More: paying over x402.
  • Is there a live catalog yet?
    No. The catalog on the site and on a local node is mock fixtures (synthetic: true), not sellable supply. Ordering becomes possible after a provider (a panel or another node) is connected.
  • What counts as a node?
    A public URL where GET /v0/services returns 200 with a JSON services array and POST /mcp with initialize returns 200 with a JSON-RPC result. Check it with npm run verify:node. More: node registry.
  • How do I connect my panel?
    With a baseUrl, an apiKey and a profile, no code; the doctor (npm run doctor) checks the panel before you hand it over. See connect a panel.
  • What is out of scope for 0.1?
    Campaigns, subscriptions, mass orders, bargaining, auto-orders, account farms and A2A. Version 0.1 has no SLA, and breaking changes are allowed without notice until /v1.

Check it on your machine

A local node, mock catalog, no keys, no money (Node.js ≥ 22.18).

bash
git clone https://github.com/opensmm-protocol/mcp-server.git
cd mcp-server
npm ci
npm run gateway
curl -s http://127.0.0.1:8080/v0/services | head -30

A step-by-step order is in the agent quickstart; for n8n see ordering from n8n; the difference from a direct API is in OpenSMM vs direct API.
