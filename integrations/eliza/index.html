Плагин OpenSMM для агента ElizaOS

Плагин добавляет агенту ElizaOS три action: search_services, get_quote, create_order. Они ходят на узел OpenSMM по POST /mcp (initialize, tools/call). Код лежит в репозитории как пример: копируете папку, запускаете узел и проверочный скрипт. Ключи и деньги не нужны, Node.js ≥ 22.18.

Открыть пример на GitHub

Каталог на узле mock: каждая услуга помечена synthetic, реальных услуг и цен нет. Заказ остаётся в статусе REQUIRES_PAYMENT.

Три шага запуска

1. Поднять узел

bash
git clone https://github.com/opensmm-protocol/mcp-server.git
cd mcp-server
npm ci
PORT=8080 npm run gateway

Узел пишет на stderr строку gateway listening on http://localhost:8080 (...; provider: mock, mock catalog — not real supply). Сбои запуска — сбои запуска узла.

2. Проверить цепочку во втором терминале

bash
node examples/eliza/smoke.mjs http://127.0.0.1:8080

Скрипт проходит поиск → котировка → заказ → повтор с тем же clientReference. Повтор возвращает тот же orderId, второй заказ не создаётся, код выхода 0.

3. Подключить плагин к своему агенту

Скопируйте examples/eliza/plugin.mjs в проект агента, зарегистрируйте плагин в персонаже и укажите адрес узла http://127.0.0.1:8080/mcp. Версия ElizaOS, под которую написан пример, указана в README папки: API фреймворка меняется между версиями, плагин сделан тонким.

Что делает каждый action

  • search_services — ищет услугу в каталоге узла; на mock-узле каждая услуга synthetic.
  • get_quote — нужны serviceId, quantity, link.
  • create_order — нужны quoteId, link, clientReference. Один clientReference даёт один заказ на любом транспорте.

REST-эквиваленты тех же операций: GET /v0/services, POST /v0/quotes, POST /v0/orders.

Честные ограничения

  1. Каталог — mock (synthetic: true): реальных услуг, цен и исполнения нет, оплата не проходит.
  2. Заказ остаётся REQUIRES_PAYMENT: плагин не платит и ничего не исполняется.
  3. Это пример для копирования, не опубликованный npm-пакет и не часть репозитория ElizaOS. Зависимости @elizaos/* в ядре OpenSMM нет.
  4. Точные опции и версия ElizaOS — в README примера.
  5. Другие стеки: быстрый старт агента, LangChain, OpenAI Agents SDK.
